GitHub

Dépôt source unique (lumeniaindustrie-stack/Lumenmarket). Chaque git push sur main déclenche automatiquement le déploiement des deux sites Cloudflare Pages.

Cloudflare Pages

Héberge deux sites statiques sans serveur : lumen-marches (espace client) et lumen-pilotage (tableau de bord admin). CDN mondial, HTTPS automatique, zéro infrastructure à gérer.

Supabase

Base de données PostgreSQL managée avec Auth, RLS et triggers. Les sites lisent et écrivent via l'API REST avec la clé publishable. Les agents n8n utilisent la clé service côté PC (jamais dans le navigateur).

n8n (local)

Orchestrateur de workflows sur le PC de Marin. Démarre automatiquement au démarrage Windows (port 5678). Surveille Supabase en polling et exécute les 5 agents selon leur calendrier.

Ollama (local)

Modèle IA qwen2.5:7b tournant en local sur le PC (port 11434). Utilisé par l'agent B pour noter les offres, par C pour répondre au chat, et par D pour analyser les DCE.

Agents A & B

A collecte les offres du BOAMP toutes les 2h (6h–20h) et les stocke dans Supabase. B les trie et note chaque matin en semaine à 6h45, puis envoie la veille par email.

Agents C & D

C répond aux questions des clients (chat) toutes les 15 sec. D analyse les DCE déposés par les clients toutes les 20 sec, avec retry automatique et email de résultat.

Agent G – Contrôleur

Surveille A, B, C, D et Ollama toutes les heures de 7h à 22h. Envoie un email d'alerte si un problème est détecté (sans répéter pendant 6h) et un rapport quotidien à 21h.

Brevo SMTP

Service d'envoi d'emails. Utilisé par B (veille quotidienne), D (résultat d'analyse au client), et G (alertes et rapport à Marin). Credentials stockées uniquement dans n8n, jamais dans le code.
